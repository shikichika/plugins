# CounterDeadlock

TLC は 4 状態、3 ステップに到達しました。チャートは 4 状態、4 本の矢印を描画します。
制約によって除外される 1 ステップがルールのパスを終端しており、チャートにはそれが含まれます。TLC はそのようなステップの後にルールをチェックしますが、そのステップは実行しません。
チャートには TLC が報告したデッドロックのみが印されます。CONSTRAINT や ACTION_CONSTRAINT の下では、チャート上でステップを持たない状態であっても、制約によって除外されたステップが存在することがあり、TLC はそれをデッドロックとして数えません。

## NotThree が破られる
最短パスは 1 ステップです:
0. 0
1. Jump: 3

## NoDeadlock が破られる
最短パスは 3 ステップです:
0. 0
1. Inc: 1
2. Inc: 2
3. Inc: 3
