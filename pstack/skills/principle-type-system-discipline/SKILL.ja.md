# 型システムの規律

不可能な状態、不一致なプリミティブ、未処理のバリアントをコンパイラに拒否させよ。

- **意味的プリミティブにブランドを付けよ。** 2つの引数が同じプリミティブ型を共有しつつ異なる意味を持つなら、それぞれに専用の型を与えよ。生成時に一度だけ検証せよ。
- **外部データはパースされるまで型なしである。** JSON、RPCペイロード、CLI引数、設定、環境変数、データベース行は、境界で型付きモデルを返すパース関数を通せ。
- **信頼できるスキーマから型を導出せよ。** スキーマファイルが形状を所有しているなら、平行して手で書き起こすのではなく、そこから型を導出せよ。

TypeScriptの構文については、**typescript-best-practices** スキルを参照。
