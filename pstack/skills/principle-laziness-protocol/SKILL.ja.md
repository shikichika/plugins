# 怠惰のプロトコル

- **判断を集約する。** 同じ選択を複数の場所で繰り返さない。1つの真実の源の背後に置き、結果は単純なフラグとして渡す。
- **差分を最小化する。** 問題を解決する最小の変更を行う。「エレガントな」ボイラープレートより、行数が少ない方が勝つ。
