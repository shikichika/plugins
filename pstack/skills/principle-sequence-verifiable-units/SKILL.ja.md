# 作業を検証可能な単位に順序付けよ

作業を、それぞれがチェック可能な状態で終わる小さな単位として順序付けせよ。現在の単位がグリーンになるまで次へ進むな。

一括処理、移行、または類似編集の連続において、各単位はひとつの括り（bracket）である: 既知の良好な状態、1つの変更、チェックの実行、次へ進む。ツールが編集を行う場合でも、単位ごとのチェックは実行せよ。

作業を証明する順序で届けよ: 失敗するテストを先に、次に修正。再構成の前に削減。処置の前にベースライン。各コミットは単独で成立する。
