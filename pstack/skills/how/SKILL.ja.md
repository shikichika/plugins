# How

コードベースを探索し、「X はどのように動作するか？」という質問に答える。

スコープが曖昧な場合は、自分の解釈を述べて探索する。ユーザーはリダイレクトできる。

## 1. 説明

`subagent_type: generalPurpose` と `readonly: true` で Task サブエージェントを 1 つ起動し、1 パスで探索と説明を行う。ユーザーの質問と以下のブリーフを渡す:

> あなたはシニアエンジニア向けにアーキテクチャの説明を書いています。コードベースを探索し、この領域に不慣れなシニアエンジニアが読んでしっかりとした mental model を持ち帰れる説明を書いてください。そのエンジニアは、アーキテクチャを十分に理解し、自信を持ってそこで作業を開始できるようになるべきです。あなたはコードベースへの読み取り専用アクセスを持っています。

## 2. 提示

サブエージェントの出力を提示する。明確化のための軽微な編集や会話からのコンテキスト追加は問題ない。実質的に書き直してはいけない。
