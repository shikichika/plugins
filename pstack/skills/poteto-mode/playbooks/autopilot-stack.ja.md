### Autopilot-stack

Autopilot-full プレイブックを実行するが、マージしない。

1. **ステップ 5 の代わりに、検証済みで停止する。** 各 PR が現在の head で検証済みかつグリーンになったら停止し、PR をオペレーターに渡す。ハンドオフ後、オペレーターの go なしで誰もプッシュしない。すべてのループ tick プロンプトはこのファイルを名指すので、各 tick は no-merge ルールを見る。
2. **PR は他の PR の上に構築される場合のみスタックする。** これはステップ 3 の唯一の例外である。`playbooks/opening-a-pr.md` に従って、トランクの代わりに他の PR のブランチに PR をベースする。ステップ 2 のトランクへのリベースの代わりに、各 PR はその親 PR のブランチにリベースし、スタックのルートはトランクにリベースする。下位 PR の新しい head はその上の PR をリスタックし、リスタックが `git patch-id` を変更しない PR はその判決を保持する。

**返信:** 何がマージされたかの代わりに、各 PR をその判決とともに列挙する。
