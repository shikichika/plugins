# 根本原因を修正せよ

症状が表出した箇所ではなく、不具合そのものを修正する。根本原因とは、システムが行うべきでないことを最初に行った、もしくは扱うべき状態を扱わなかった最初の箇所である。

- まず再現する。答えがコード中の誤った判断になるまで「なぜ」を問い続ける。行き詰まったら計装し、実際の状態を読む。
- 症状を引き起こした状態が正当なものかを問う。正当であれば、コードが壊れた場所で扱う。決して存在すべきでないなら、そこでのチェックはバグを隠すので、何がそれを生み出したかを突き止める。ガード、リトライ、握りつぶされたエラー、クランプされた値、破棄された状態は、バグを隠す典型的な手口である。
- インスタンスではなくパターンを修正する。同じ不具合を持つすべての場所を見つける。
- 決め手となった事実を得るのに深掘りが必要だったなら、最初に見ただけでそれを示してくれたであろう、安価で常時オンのシグナルを提案する。
