# 呼び出し元を移行し、レガシーAPIを削除する

- 新しい契約をアサートするようにテストを更新し、リファクタリング前の実装詳細のみを保護しているテストは削除する

**適用対象:**
- 外部ユーザーが後方互換性に依存していない
- プロジェクトが調整された破壊的変更を受け入れられる
- 新しいAPIが簡素化またはリファクタリングの取り組みの一部である
