# ドメインをモデリングする

ドメインを条件分岐の中に散らばせるのではなく、データ構造にエンコードせよ。適切な構造は不正な状態を表現不可能にし、分岐を消す。

散らばったブール値やフェーズチェックではなく状態マシンを、緩いパラメータではなく型付きモデルを、ファイルをまたいで散らばる分岐ではなくマップ・レジストリ・判別共用体を、場当たり的な変更ではなくreducerを、そしてアクセスパターンが求める場所ではインデックス・キュー・正規化されたコレクションを使え。

無理に適用するな。形状が明確でローカルで成長しそうにないときは退屈なコードのままにせよ。分岐や不正状態を取り除かずに間接層を増やすだけの抽象化を疑え。

これをスキップしたサイン: if/elseチェーンがもう1分岐増える機能、または最初のブール値と同期を保たねばならない2つ目のブール値。
