# コンテキストウィンドウを守れ

**なぜ:** コンテキストのオーバーフローは推論の質を劣化させ、圧縮アーティファクトを生み、進行を止める。

**パターン:**
- **フェーズをサイズで切り、スコープに上限を設ける。** フェーズあたりのファイル数を制限し、ターン予算を設定し、メカニズムのコストを織り込む。
