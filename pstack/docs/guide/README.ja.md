# pstack ガイド

pstack は、エージェントを細かく管理するのをやめたときに最も威力を発揮します。あなたは何をしたいか、そしてどうなれば完了とわかるかを伝えるだけです。`/poteto-mode` がプレイブックを選び、各ステップに応じて他のスキルを実行し、証拠を示してくれます。このガイドでは、現実的なプロンプトを通してその習慣を身につけます。

学ぶ内容は次のとおりです。

1. [pstack をセットアップする](./01-setup.md)。プラグインをインストールし、モデルを選びます。
2. [`/poteto-mode` を通して作業をルーティングする](./02-poteto-mode.md)。ゴールを与え、プレイブックが選ばれる様子を見ます。
3. [コードを理解する](./03-understand.md)。読み取り専用の調査を行い、編集を始める前に `/how`、`/why`、`/teach`、`/recall` を使います。
4. [変更を設計する](./04-design.md)。コードが形を固めてしまう前に、`/architect`、`/arena`、`/swarm`、`/interrogate`、プロトタイプ、計画を活用します。
5. [変更を作り、差分をきれいにする](./05-build-and-clean.md)。ビルド用プレイブック、`/tdd`、`/unslop`、`/no-comments` を使います。
6. [検証して出荷する](./06-verify-and-ship.md)。実アプリで挙動を証明し、テストが届きにくい領域を形式的に検証し、`/benchmark-checklist` で数値を吟味し、焦点の定まった PR を開いてマージまで持っていきます。
7. [寝ている間に作業を進める](./07-overnight.md)。ループを回す前の信頼、オーバーナイト契約、監査できる決定ログ、そして単一エージェントを超えてスケールする Projects と自動化を学びます。
8. [原則の名前で舵を取る](./08-principles.md)。作業中のエージェントを軌道修正するための 24 の名前を紹介します。
9. [自分のものにする](./09-make-it-yours.md)。自分専用のモード、繰り返されるミスへの `/correct`、スキル変更のテスト方法を扱います。
10. [レシピと落とし穴](./10-recipes-and-pitfalls.md)。コピペできるプロンプトと、避けるべきミスをまとめています。

初回は順番に読んでください。それ以降は、各ページは独立して読めます。

行き詰まったり、どのスキルが合うかわからないときは、[`/poteto-help`](../../skills/poteto-help/SKILL.md) に質問を打ち込んでください。

```text
/poteto-help which skill should i use to review this branch?
```

答えに加え、送るべきプロンプトと、答えの根拠となったスキルやガイドページへのリンクを返してくれます。pstack の実行は実際にトークンを消費するため、`/poteto-help` 自体は作業を開始せず、あなたが準備できたときにプロンプトを送ります。実行はあなたがそれを打ち込んだときだけです。

## もし一つだけ覚えておくなら

エージェントに、自分の言葉でゴールとそれを確認する方法を与えてください。

```text
/poteto-mode the export writes duplicate rows when a retry lands mid-run. repro first, then fix and verify.
```

プレイブック名を挙げたりスキルを列挙したりする必要はありません。「repro first」とチェック可能な結果があれば、`/poteto-mode` にとってのルーティング信号としては十分です。Bug fix プレイブックにマッチし、ステップを todo リストにコピーし、各ステップが発火するたびに適切なスキルを呼び出します。

次は [pstack をセットアップする](./01-setup.md) です。
